# Lunar Ice Detection using Chandrayaan-2 DFSAR Data

## Overview

This project focuses on the detection and characterization of subsurface ice in the Lunar South Polar Region using Chandrayaan-2 DFSAR radar observations.

## Objectives

- Analyze DFSAR radar signals
- Detect potential subsurface ice deposits
- Rank landing sites
- Generate rover traverse plans
- Create lunar ice probability maps
